# VISUS — Brand Guidelines

Source of truth for the VISUS identity. VISUS is the permanent product name
(formerly Lingua Flow; the rename is branding only — user data, backups and
license keys carry over unchanged).

## Name and messaging

| Element | Value |
|---|---|
| Product name | VISUS (always all-caps) |
| Tagline | See words. Learn worlds. |
| Japanese subtitle | 言葉の旅 |
| One-liner | Learn languages by reading the real web. |
| Voice | Warm, editorial, plain-spoken. Local-first and honest about limits; never hype. |

Canonical strings live in code at `src/brand.ts` (`APP_NAME`, `APP_TAGLINE`,
`APP_SUBTITLE_JA`, `APP_DESCRIPTION`, backup filenames). Use them instead of
hard-coding the name in UI copy.

## Visual identity — Japanese editorial

| Token | Value | Use |
|---|---|---|
| Warm ivory (washi) | `#f4ecdb` | Page paper / background (design frames 1–14) |
| Charcoal | `#2b251d` | Ink, primary text (dark “sumi” paper: `#37322a`) |
| Clay | `#a9714b` | Primary UI accent: active nav, level squares, chart highlight |
| Terracotta | `#c2410c` | Logo V mark, small accents |
| Petrol blue | `#0f4c5c` | Secondary accent, book covers, iris dot |
| Iris highlight | `#5aa9c2` | Small logo detail only |
| Taupe | `#a79c8a` | Chart bars, secondary fills |

Design reference: the 14 VISUS frames (cover, Home light/dark, Reading
light/dark, Discover, Library, Videos, Collection, Review, Statistics,
Dictionaries, Languages, Settings). Layout signatures: serif display titles,
small-caps kickers with hairline rules, flat sections (no rounded cards),
square learning-level buttons, muted sepia editorial photography in
`public/images/` (cropped from the design frames).

- Typography: serif display (`Georgia / Noto Serif CJK`) for headings and the
  wordmark feel; system sans for UI body text.
- Logo: charcoal rounded tile, terracotta "V" (an open book / eye), petrol
  iris with an ivory pupil. Sources: `public/logo.svg`, `public/favicon.svg`;
  extension PNGs in `public/icons/` are generated by `node scripts/gen_icons.mjs`.
- Do not use the old wave mark or the name "Lingua Flow" in any user-visible
  surface. The old name may appear only in code comments explaining preserved
  internal identifiers.

## Preserved internal identifiers (do not rename)

These keep existing installs working and are not branding:

- IndexedDB database name `lingua-flow` (`src/storage/db.ts`)
- Firefox add-on ID `lingua-flow@example.local` (`scripts/manifests.mjs`)
- License key prefix `LF1-`, encrypted-backup format `lingua-flow-encrypted`
- Runtime message types `LF_*`, CSS classes `lf-*`, storage keys `lf:*`,
  `BroadcastChannel('lingua-flow')`

New user-visible exports use `visus-backup.json`,
`visus-backup-encrypted.json` and `visus-vocabulary-<lang>.json`.
