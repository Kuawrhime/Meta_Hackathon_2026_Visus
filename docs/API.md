# API & services reference — VISUS

## Runtime messages (content → background)
| Type | Payload | Response |
|---|---|---|
| `LF_GET_SETTINGS` | — | `Settings` |
| `LF_SET_SETTINGS` | `{ patch }` | updated `Settings` |
| `LF_STATUS_MAP` | `{ lang }` | `{ [lemma]: WordStatus }` |
| `LF_ENCOUNTERS` | `{ lang, words[] }` | `true` (batched, deduped server-side) |
| `LF_SET_STATUS` | `{ lang, word, status }` | `VocabRecord`; broadcasts `LF_VOCAB_CHANGED` |
| `LF_GET_WORD` | `{ lang, word }` | `VocabRecord \| undefined` |
| `LF_SET_DEF` | `{ lang, word, def }` | `VocabRecord` |
| `LF_ADD_READING` / `LF_ADD_LISTENING` | `{ lang, seconds }` | `true` (clamped to 60s per call) |
| `LF_OPEN_DASHBOARD` / `LF_OPEN_READER` | `{ url? }` | opens extension pages |

## Core services
- `VocabularyService.get/all/statusMap/encounter/setStatus/setCustomDefinition/addPhrase/remove/counts/importRecords` — IndexedDB-backed, lemma-normalized (`lang:lemma` ids).
- `DictionaryService.lookup/lookupMany/size/allEntries/parseImport/registerCustom` — bundled dictionaries in `src/dictionary/data/*.json` (row format: `[word, lemma, phonetic, pos, definition, gloss, example, frequencyRank, forms]`), regenerated by `scripts/gen_cjk.mjs` + `scripts/convert_dicts.mjs` from `scripts/gen_dicts.py`.
- `TextSegmentationService.segmentText/normalizeWord/lemmatize/detectLanguage` — tokens `{ text, start, end, isWord }`.
- `HighlightingService.highlightRoot/highlightTextNode/refreshWordEverywhere/pageCounts` — DOM highlighting shared by web pages, reader and books.
- `AudioService.speak/speakWord/speakSentence` — Web Speech with settings-driven voice/rate.
- `BackupService.exportJSON/exportEncrypted/decryptBackup/importJSON/autoBackup/download` — AES-GCM (PBKDF2 100k) encrypted backups.
- License: `generateLicenseKey/verifyLicenseKey/activateLicense/checkLicenseForNewWord` (`FREE_LIMIT = 1000`).

## Content-script keyboard map
Grading: `1–4`, `K`, `X`, `0`, `Esc`; navigation `Alt+←/→`. Subtitles: `A/S/D` navigate, `Q` auto-pause, `E` blur/reveal, `C` toggle, `W` vocabulary.
