# Architecture — VISUS

## Layers
- **Content script** (`src/content`) — runs on web pages. Owns the highlighting engine loop (TreeWalker + MutationObserver), tooltip/panel/counter UI, YouTube subtitle overlay and chatbot streaming support. It never touches IndexedDB directly: vocabulary lives in the extension origin, so all vocabulary reads/writes go through `chrome.runtime` messages to the background worker. Dictionaries are bundled into the content bundle, so lookups are local and instant.
- **Background service worker** (`src/background`) — the single writer for vocabulary/statistics. Handles `LF_GET_SETTINGS`, `LF_STATUS_MAP`, `LF_ENCOUNTERS` (batched), `LF_SET_STATUS` (broadcasts `LF_VOCAB_CHANGED` to all tabs so every open page recolors instantly), reading/listening time accrual, context menus, install onboarding and periodic local auto-backups.
- **Extension pages** (`src/popup`, `src/dashboard`) — React + Tailwind. The dashboard hosts Home, Reading (reader), Books, Videos, Vocabulary, Statistics, Dictionaries, Languages and Settings as hash routes, all reading real IndexedDB data through the service layer.
- **Services** (`src/services`) — framework-free business logic: `VocabularyService` (lemma-normalized records, encounters, counts), `DictionaryService` (lazy-loaded bundled JSON dictionaries + JSON/CSV/TSV/TXT import adapters), `TextSegmentationService` (Intl.Segmenter / Chinese max-match / European tokenization + lemmatization), `HighlightingService` (shared by content script, reader and book reader), `ReadingStatisticsService` (+ visibility-gated `ReadingTimer`), `AudioService` (Web Speech), `TranslationService`/`LanguageDetectionService` (opt-in only), `BackupService` (JSON + AES-GCM), license (`FREE_LIMIT`, offline key check), `SettingsService`.
- **Storage** (`src/storage/db.ts`) — a small IndexedDB wrapper (`vocab`, `books`, `bookData`, `stats`, `dictCache`, `meta` stores) with a schema-version migration hook.
- **Browser compatibility** (`src/utils/browser.ts`) — one shim over `chrome.*`/`browser.*` promise styles, storage fallbacks for dev pages, and browser detection. Manifests per browser are generated by `scripts/manifests.mjs`; builds use the Vite Node API (`scripts/build.mjs`, `configFile:false`) into `dist/<browser>/`.
- **Workers** (`src/workers/dictWorker.ts`) — off-main-thread segmentation for large texts.

## Data flow (grading a word)
Click word (content) → panel → `LF_SET_STATUS` → background writes IndexedDB via `VocabularyService` → background broadcasts to all tabs + `BroadcastChannel` → every page calls `refreshWordEverywhere` (no rescan). The dashboard observes the same write through its own service call.

## Privacy boundaries
Translation/AI are the only network paths, both gated by explicit settings flags and user API keys. Books and subtitles are processed locally. Scanned-PDF OCR loads Tesseract.js only on demand.
